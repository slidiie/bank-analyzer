Как скачать выписку Приорбанк

Выписка нужна, чтобы увидеть траты не списком операций, а по категориям: сколько ушло на продукты, кафе, подписки, что выросло против обычного месяца. Ниже, где её взять в Приорбанк.

В мобильном приложении

  • Приложение Prior Online, раздел «История»: значок фильтра справа вверху (продукт, тип операции, период) показывает операции.
  • Официальная выписка: «Еще» → «Заявки на продукты» → «Заказ документов» → «Заказ справок и выписок», тип «Выписка по счету».

Другие способы

  • Prior Online, раздел «История»: значок фильтра справа вверху (продукт, тип операции, период) показывает операции.
  • Официальную выписку закажите так: «Еще» → «Заявки на продукты» → «Заказ документов» → «Заказ справок и выписок», тип документа «Выписка по счету». По данным банка, выписка по счёту бесплатна.

Сколько ждать

Выписка по заявке приходит не сразу: срок виден в самой заявке. Пока ждёте, можно посмотреть пример отчёта. Если банк предлагает выписку и в CSV, берите CSV: в нём есть код магазина, и категории определяются точнее, чем по PDF.

Сведения собраны из открытых материалов банка (ноябрь 2026), названия пунктов меню могут отличаться. Источник: Приорбанк: заказ справок и выписок в Prior Online.

Что делать с выпиской

Загрузите файл на Fernwood: сайт читает выписки Приорбанк, раскладывает траты по категориям и пишет «Итог месяца» простыми словами: что выросло, сколько уходит на подписки, сколько ушло на мелкие покупки.

Без регистрации. Файл разбирается в вашем браузере и никуда не отправляется: можно проверить, отключив интернет.
